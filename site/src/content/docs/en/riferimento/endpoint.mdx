Base URL: `https://corso-api-json.giuseppebosi.com/api/v1`. Interactive documentation generated from OpenAPI: [Swagger UI](/api/docs); the schema can be downloaded from `/api/openapi.json`.

**Sandbox**: the endpoints marked ✍️ require `Authorization: Bearer <token>` (token from `POST /sandbox`). The others also work without a token, on the public dataset; with the token they read your copy.

**Limit**: 30 requests per minute per IP on the public server (120 locally) → `429` with `Retry-After`. **Errors**: always `{"error": {"code", "message", "details"?}}`. Error messages are in Italian; the `code` values are stable identifiers in English.

## Headers you will find in the responses

| Header | Where | Meaning |
|---|---|---|
| `X-Request-Id` | all | request identifier, to quote in logs |
| `ETag`, `Cache-Control` | `GET /books/{id}` (and `Cache-Control: no-store` with a token) | conditional caching (ch. 14) |
| `Location` | 201 of `POST /books`, `POST /orders` | URL of the created resource |
| `Retry-After` | 429 | seconds to wait |
| `Access-Control-*` | all | open CORS (ch. 15) |
| `Content-Encoding` | compressed responses | `gzip` from the API, or `zstd` from Caddy in production (ch. 14) |
| `Strict-Transport-Security`, `X-Frame-Options`, … | production only | added by the reverse proxy (Caddy) |
