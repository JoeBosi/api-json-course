## Goals

- Read values three or four levels deep without `KeyError` / `TypeError`.
- Use **jq** from the terminal to explore, filter and transform JSON.
- Know **JSONPath** to express paths declaratively.
- Understand how an API produces nested JSON by "following" foreign keys (`?expand=`).

## Theory

Real JSON is never flat. Order 1 with its customer and the books of its lines is a tree **four levels** deep: order → lines → book → author. To reach the author name of the first book the path is `items[0].book.author_name`.

Three ways to walk a tree:

1. **Direct access** (`o["items"][0]["book"]["author_name"]`): fast, but if a piece is missing the program stops with an exception.
2. **Safe access**: `.get()` with a default in Python, `?.` (optional chaining) and `??` in TypeScript. It returns `None`/`undefined` instead of blowing up.
3. **A path language**: **JSONPath** (`$.items[*].book.title`) or **jq** (`.items[].book.title`). Ideal for exploring unfamiliar data or for terminal scripts.

How does nested JSON come about? The database has separate tables linked by foreign keys (`orders.customer_id → customers.id`, `order_items.book_id → books.id`). The server, if you ask with `?expand=`, replaces the id with the whole object. Without `expand` you only get `customer_id: 39` and need a second request: you will see this in detail in Section 2, chapter 5.

### jq in eight moves

We work on the list of books (`/api/v1/books?limit=100`, an object with `items` and `meta`).

<Curl cmd={`URL='https://corso-api-json.giuseppebosi.com/api/v1/books?limit=100'

curl -s "$URL" | jq '.items[] | {title, price}'

# 2. filtro + conteggio
curl -s "$URL" | jq '[.items[] | select(.price < 8)] | length'

curl -s "$URL" | jq -r '.items | sort_by(-.price) | .[0:3][] | "\\(.price)\\t\\(.title)"'

## Python and TypeScript

<Tabs syncKey="lang">
<TabItem label="Python">
```python
# pip install httpx jsonpath-ng
import httpx
from jsonpath_ng.ext import parse

BASE = "https://corso-api-json.giuseppebosi.com/api/v1"
o = httpx.get(f"{BASE}/orders/1", params={"expand": "items.book,customer"}).json()

# accesso diretto: chiaro, ma KeyError se manca un pezzo
print(o["items"][0]["book"]["author_name"])          # Pietro Galli

# accesso sicuro: .get() a catena con default
print(o.get("customer", {}).get("city"))             # Bari
print(o.get("customer", {}).get("phone", "n/d"))     # n/d  (campo inesistente)

# JSONPath: percorsi dichiarativi, anche con wildcard e filtri
print([m.value for m in parse("$.items[*].book.title").find(o)])
print([m.value for m in parse("$.items[?(@.quantity>=1)].book.author_name").find(o)])

lista = httpx.get(f"{BASE}/books", params={"limit": 100}).json()
economici = [m.value for m in parse("$.items[?(@.price<8)].title").find(lista)]
print(len(economici))                                # 3
```

Notes: `jsonpath_ng.ext` (not `jsonpath_ng`) is needed for `[?(...)]` filters. For a fixed path where you need no flexibility, chained `.get()` calls are more readable and faster.
</TabItem>
<TabItem label="TypeScript">
```ts
// node --experimental-strip-types naviga.ts
const BASE = "https://corso-api-json.giuseppebosi.com/api/v1";
const o = await (await fetch(`${BASE}/orders/1?expand=items.book,customer`)).json();

// accesso diretto: TypeError se un pezzo è undefined
console.log(o.items[0].book.author_name);            // Pietro Galli

// optional chaining ?. e nullish coalescing ??
console.log(o.customer?.city);                       // Bari
console.log(o.customer?.phone ?? "n/d");             // n/d
console.log(o.items?.[5]?.book?.title ?? "nessuna sesta riga");

// percorso da stringa, senza librerie: una funzione di 5 righe
function leggi(obj: unknown, percorso: string, fallback?: unknown) {
  return percorso.split(".").reduce<any>((acc, k) => (acc == null ? undefined : acc[k]), obj) ?? fallback;
}
console.log(leggi(o, "shipping_address.zip"));       // 15399
console.log(leggi(o, "items.0.book.price"));         // 12.04
console.log(leggi(o, "items.9.book.price", 0));      // 0

// "jq in TypeScript": map/filter/sort sui dati
const lista = await (await fetch(`${BASE}/books?limit=100`)).json();
const top3 = [...lista.items].sort((a, b) => b.price - a.price).slice(0, 3).map((b) => `${b.price}\t${b.title}`);
console.log(top3.join("\n"));
```

For real JSONPath in TS there is `jsonpath-plus` (`npm install jsonpath-plus`): `JSONPath({ path: "$.items[*].book.title", json: o })`.

## Exercise

With jq (or in Python/TS), starting from `/api/v1/categories?tree=true`:

1. Print the names of the **root** categories only.
2. Print, for each root, the names of its subcategories.
3. Add up `books_count` over all categories, at any level (jq hint: `..` recursively visits every node).

<details>
<summary>Solution</summary>

```bash
URL='https://corso-api-json.giuseppebosi.com/api/v1/categories?tree=true'
curl -s "$URL" | jq -r '.items[].name'                                    # 1
curl -s "$URL" | jq -r '.items[] | "\(.name): \([.children[].name] | join(", "))"'   # 2
curl -s "$URL" | jq '[.. | .books_count? | numbers] | add'                # 3 → 80
```

`..` produces every value in the tree; `.books_count?` tries to read the key, ignoring errors on non-objects; `numbers` discards the `null`s.
</details>

## Common mistakes

- **`o["items"][0]` on an empty list** → `IndexError`/`undefined`: check the length or use `?.[0]`.
- **Confusing `null` with "missing key"**: in jq and JS both arrive as `null`/`undefined`; if the difference matters, use `has("k")` (jq) / `"k" in obj` (JS) / `"k" in d` (Python).
- **Forgetting the quotes around a URL with `?` and `&`**: the shell silently splits the command.
- **`jq '.items[].price | add'`** does not work: `add` wants an array, so `[.items[].price] | add` or `.items | map(.price) | add`.

## Summary

Direct access when the shape is guaranteed, safe access (`.get`, `?.`) when something may be missing, jq/JSONPath to explore. And remember: nesting comes from the relations between tables, which the API expands for you. Next chapter: when the JSON is too big to fit in memory.
