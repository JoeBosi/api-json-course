## The test server

`/api/v1` is a **teaching server**, not a service: the data is made up, the private copies
(sandboxes) expire after a few hours, there is a per-minute request limit, and the API stays
**off when nobody uses it** (you switch it on from [Switch on the test API](/en/api-attiva/)).
It must not be used as the backend of anything else, and it may change or disappear without
notice.
