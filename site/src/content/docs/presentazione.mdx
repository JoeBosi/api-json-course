## A chi si rivolge

A chi conosce le basi di **Python** e/o **JavaScript** (variabili, funzioni, liste e dizionari/oggetti) e vuole padroneggiare due cose che oggi stanno ovunque:

1. **JSON**, il formato con cui programmi, API e database si scambiano dati;
2. **le API HTTP** con cui si interrogano (e si modificano) i dati di un database, da un semplice `GET` fino a query su più tabelle legate da chiavi primarie ed esterne.

Non serve conoscere SQL: lo incontrerai gradualmente nella Sezione 2, sempre attraverso l'API.

## Come è organizzato

Ogni capitolo segue lo stesso schema:

- **Obiettivi** — cosa saprai fare alla fine.
- **Teoria** — il minimo che serve, con esempi.
- **curl, spiegato opzione per opzione** — la richiesta "nuda", per capire davvero cosa passa sul filo.
- **Python e TypeScript affiancati** — lo stesso esempio nei due linguaggi (scegli la scheda: il sito la ricorda).
- **Prova subito** — un pulsante che esegue la richiesta dal browser contro il server di prova e mostra la risposta.
- **Esercizio** con soluzione, ed **errori comuni**.

## Ascoltare invece di leggere

Sotto il titolo di ogni capitolo c'è un piccolo pulsante **🔊 Ascolta**. Non parte mai da solo: se lo apri, la pagina viene letta paragrafo per paragrafo, con il paragrafo in lettura evidenziato. Puoi mettere in **pausa**, **fermare**, saltare avanti e indietro, cambiare velocità e scegliere la **voce**: la lettura usa la sintesi vocale del tuo browser, quindi le voci disponibili sono quelle del tuo dispositivo (in Edge le voci «Natural», su Mac e iPhone quelle «Avanzate» sono le migliori). ## Il server di prova

`https://corso-api-json.giuseppebosi.com/api/v1` espone il catalogo di una libreria inventata, la **Libreria Aurora**: 80 libri, 20 autori, 10 categorie (annidate), 40 clienti, 120 ordini, recensioni e tag. Le tabelle sono legate da chiavi esterne, proprio come in un database reale. Descrizione completa: [Il dataset](/riferimento/dataset/).

- **Senza token** leggi i dati pubblici (sola lettura).
- **Con una sandbox** (un token che crei con una chiamata) lavori su una **copia privata** del database: crei, modifichi, cancelli, e nessun altro lo vede. La copia scade dopo alcune ore di inattività.
- C'è un limite di richieste al minuto per indirizzo IP: è un server didattico, non un servizio di produzione.
- Documentazione interattiva (Swagger UI): [/api/docs](/api/docs).

## Puoi anche farlo girare sul tuo computer

Tutto il corso — sito e server — è un progetto open: `git clone`, poi `./bootstrap.sh` e `cd api && uv run fastapi dev app/main.py --port 8795`. Gli esempi puntano allo stesso percorso `/api/v1`, quindi funzionano uguali.
