Base URL: `https://corso-api-json.giuseppebosi.com/api/v1`. Documentazione interattiva generata da OpenAPI: [Swagger UI](/api/docs) e [ReDoc](/api/redoc); lo schema è scaricabile da `/api/openapi.json`.

**Sandbox**: gli endpoint marcati ✍️ richiedono `Authorization: Bearer <token>` (token da `POST /sandbox`). Gli altri funzionano anche senza token, sul dataset pubblico; con il token leggono la tua copia.

**Limite**: 30 richieste al minuto per IP sul server pubblico (120 in locale) → `429` con `Retry-After`. **Errori**: sempre `{"error": {"code", "message", "details"?}}`.

## Header che troverai nelle risposte

| Header | Dove | Significato |
|---|---|---|
| `X-Request-Id` | tutte | identificativo della richiesta, da citare nei log | 
| `ETag`, `Cache-Control` | `GET /books/{id}` (e `Cache-Control: no-store` con token) | cache condizionale (cap. 14) |
| `Location` | 201 di `POST /books`, `POST /orders` | URL della risorsa creata |
| `Retry-After` | 429 | secondi da attendere |
| `Access-Control-*` | tutte | CORS aperto (cap. 15) |
| `Content-Encoding`, `Strict-Transport-Security`, … | solo in produzione | aggiunti dal reverse proxy (Caddy) |
